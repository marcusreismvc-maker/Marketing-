Conta e nuvem

Supabase (sincronização entre dispositivos)

Não conectado.
Crie um projeto gratuito em supabase.com, rode o SQL indicado abaixo e cole aqui a URL + a chave anon public.
SQL para criar a tabela (rode uma vez no SQL Editor do Supabase) 
-- Rode cada bloco SEPARADAMENTE no SQL Editor

-- BLOCO 1
create table if not exists public.marketing_data (
  user_id uuid primary key references auth.users (id) on delete cascade,
  posts jsonb not null default '[]'::jsonb,
  cats jsonb not null default '[]'::jsonb,
  guide text,
  settings jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now()
);

-- BLOCO 2
alter table public.marketing_data enable row level security;

-- BLOCO 3 (se der erro de "already exists", ignore)
create policy "own data"
  on public.marketing_data
  for all
  using (auth.uid() = user_id)
  with check (auth.uid() = user_id);
